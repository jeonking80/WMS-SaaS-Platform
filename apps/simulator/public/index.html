시험 콘솔 접근

1. 시험 연결

WMS 주소와 회사는 서버의 환경 설정으로 고정합니다. 연계·처리·작업·승인·준비 키는 화면에 표시하지 않습니다.

2. 가상 거래처 · 시나리오 편집

설정형 혼합 실물 패턴

부족·파손·오스캔 비율은 ‘설정형 혼합’에서 적용합니다. 부족은 전체예약 거절 후 보충 수령, 파손은 격리 후 대체 피킹, 오스캔은 거절 후 정상 재시도를 수행하며 각각 독립 대사합니다.

작업자 · 근무 · 인계

인계는 별도 책임자 키로 WMS 담당자를 실제 변경합니다. 이후 선택한 작업자만 잔량을 처리합니다. 중단 후 같은 실행을 재개하세요. 근무시간 밖에는 새 요청을 기다리며 미확인 결과 조회는 계속합니다.

기준 시나리오의 수량은 수락 기준에 고정됩니다. 설정형 혼합은 seed·업무수·수량분포·비율로 실제 수령부터 출하까지 수행합니다. 단순 패턴 공급은 외부 사건만 생성합니다. 사용 이력이 없는 전용 시험 품목만 시작할 수 있습니다.

3. 실행 제어 · 작업자 인계

일시정지는 신규 공급·자동 명령을 멈춥니다. 진행 중 요청은 결과 확인 대상이며 사람 작업은 WMS에서 별도로 멈춰야 합니다. 재시작한 실행은 일시정지 상태로 복구됩니다.

4. 독립 판정 · 증거

로컬의 실물 작업 의도로 기대 재고를 계산하고, 동일 처리 버전의 WMS 재고·원장·예약과 비교합니다. 새 보고서 생성과 합격 판정은 구분됩니다. 장시간·혼잡·복원·실기기 시험은 실행 증거가 생기기 전까지 미실행입니다.

5. 실행 간 비교

운영 회사 연결·DB 직접 변경·일괄 초기화 기능을 제공하지 않습니다. 시험 이력은 SQLite에 보존합니다.
