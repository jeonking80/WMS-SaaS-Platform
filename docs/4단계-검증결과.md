# WMS Lite 4단계 검증 결과

검증일: 2026-10-20 (Asia/Seoul). Node.js 24, Next.js 16, PostgreSQL 17.9, 시스템 Chromium 환경에서 실행했다. 모든 서브에이전트는 gpt-6.1-sol이다. GitHub Actions는 사용하지 않았다.

## 완료 범위

- P4-01: 공통 입출고 확정 서비스, 출발 위치 잔량 잠금·차감, 부족 품목이 있으면 전체 미반영, 음수 원장과 POST_OUTBOUND 감사 기록.
- P4-02: 독립 DB 연결의 동시 출고, 실제 잠금 시간 초과·롤백·같은 키 재시도, 중복 요청·다른 회사·조회자 접근 검사.
- P4-03: 출고 확정/재시도 화면, 위치·품목별 참고 재고, 미저장 변경 시 확정 차단, 부족 오류 후 수정·저장, 입고 회귀 검사.

3단계 스키마를 재사용하므로 추가 마이그레이션은 없다. 기존 입고 성공 요청 해시와 재시도 계약을 유지한다.

## 실행 결과

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium NEXT_TELEMETRY_DISABLED=1 npm run verify
```

타입 검사, 단위 72개, DB 통합 28개, 프로덕션 빌드가 통과했다. E2E 22개 중 20개가 통과했고 새 출고 브라우저 2개가 알림 선택자 중복으로 실패했다. 실제 재고 부족 알림과 Next.js 화면 전환 알림이 함께 선택된 테스트 문제였다. 실제 오류 메시지를 기준으로 선택자를 좁힌 뒤 아래 명령에서 두 테스트가 모두 통과했다. 앱 동작이나 검증 조건을 완화하지 않았다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e -- tests/e2e/p4.spec.ts --grep 'P4 browser'
```

최종 고유 테스트 결과: **단위 72개 + DB 통합 28개 + E2E 22개 = 122개 통과**, 미해결 실패·생략 없음. 마지막 수정은 테스트 선택자뿐이며 앱 빌드를 다시 바꾸지 않았다.

## 주요 검증 근거

- 100개 입고를 정상 확정 경로로 만든 뒤 출고 80개 두 전표를 생성한다. 제어 연결이 잔량 행을 잠그고 독립 실행 연결 두 개가 DB 잠금 대기에 도달했음을 확인한 후 해제한다. 정확히 한 건 성공·한 건 INSUFFICIENT_STOCK, 최종 잔량 20, 출고 원장 -80 한 건, 감사 한 건, 멱등 성공 기록 한 건이다. 실패 전표는 DRAFT/version=1을 유지한다.
- 여러 품목 중 뒤쪽 품목이 부족한 경우와 잔량 행이 없는 경우 모두 현재고·원장·상태·버전·감사·성공 요청 기록 전체가 미변경이다.
- 같은 키 동시 출고와 응답 재조회는 한 번만 반영한다. 다른 키로 같은 확정 전표를 다시 처리하면 추가 반영이 없다.
- 실제 잔량 행을 잠근 채 1초 이상 유지하여 PostgreSQL 55P03 오류를 발생시킨다. 503 RETRYABLE_TRANSACTION 응답 매핑과 전체 롤백을 확인하고 잠금 해제 뒤 같은 키 재시도가 성공한다. 실제 교착을 별도로 유발하지는 않았으며 교착 오류 코드 매핑은 기존 단위 테스트에서 유지한다.
- 브라우저에서 참고 재고 100, 미저장 수량 변경 시 확정 차단, 저장 후 출고 80 확정, 잔량 20·원장 -80을 확인한다. 다시 80 출고하면 부족 오류를 표시하고 수정·저장이 가능하다.
- 서버가 확정한 응답을 브라우저에서 차단해도 최초 키로 재시도하며 출고 효과와 감사 기록은 한 건이다.
- 작업자 확정 허용, 조회자 확정 403, 다른 회사 전표 404, 위치·품목 UUID 필터 검증과 회사 격리를 확인한다. 기존 인증·입고·초안·RLS 검증도 유지한다.

## 제한과 다음 단계

참고 재고는 예약이 아니며 확정 시점에 다시 검사한다. 재고·원장 목록 검색/페이지네이션, 운영 성능 측정·외부 배포는 이번 단계 범위가 아니다. 이동 확정과 확정 취소는 아직 제공하지 않는다.

다음은 5단계 내부 이동, 원본과 연결된 반대 거래를 통한 관리자 확정 취소 및 중복·동시 취소 검증이다.
