# 6단계 성능 측정

측정 시각: 2026-10-20T01:31:34.639Z ~ 2026-10-20T01:31:43.686Z

원장 10,000건에서 주요 화면의 표시 시간 2초 목표를 이번 로컬 측정에서 충족했다. 가장 느린 화면은 재고 조회로 p95 314.9ms였다. 이 결과는 단일 로컬 환경의 관측값이며 운영 환경 응답 시간 보장이 아니다.

## 재현 방법

기존 개발 서버를 종료하고 `npm run build`를 완료한 뒤 실행한다. 로컬 `wms_lite` 데이터베이스와 `.env.local`의 기존 연결·인증 설정, `DEMO_PASSWORD`, 설치된 Chromium이 필요하다. 비밀 값은 결과에 저장하지 않는다.

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:performance
```

`scripts/performance.mjs`는 별도 production 서버를 loopback 3200 포트에 시작하고 자신이 시작한 프로세스만 종료한다. 빌드는 실행하지 않는다. 결과 기본 경로는 `/tmp/wms-p6-performance.json`이며 `PERF_REPORT_PATH`로 바꿀 수 있다. 원본 결과는 [p6-performance.json](p6-performance.json)에 보관했다.

## 측정 조건

- Linux 6.18.55, AMD EPYC 9V74 80-Core Processor. OS가 보고한 논리 CPU 5개와 메모리 35,743,760,384바이트. 실제 cgroup CPU 제한은 `400000 100000`으로 4 CPU 상당이며, 메모리 제한은 `34359738368`바이트(32GiB)다.
- Node v24.19.0, PostgreSQL 17.9, Chromium 154.0.8037.57. 기존 Next.js production 빌드를 사용했다.
- 새 전용 테넌트와 합성 관리자 계정을 매번 생성했다. 데모 A/B 데이터는 측정 대상이나 수정 대상에 포함하지 않았다.
- 품목 100개 × 로케이션 100개: 확정 입고 전표·명세·원장·잔량·감사 로그 각 10,000행, 창고 1개. 각 입고 수량은 1이며 확정 시각은 약 7일에 분산했다. 직접 SQL 행 수와 목록 API의 전체 10,000건을 확인했고 재고/원장 대사도 일치했다.
- 벌크 적재 후 관련 테이블에 `ANALYZE`를 실행해 통계를 갱신했다. 시드, 서버 시작, 로그인, 통계 갱신은 측정에서 제외했다.
- 각 API·화면별 준비 실행 1회 후 5회 측정했다. 동시 실행 수는 1이며 다른 테스트/서버 작업 없이 loopback으로 측정했다. 부하 시험이 아니다.
- API 시간은 인증된 Playwright 요청 시작부터 JSON 읽기 완료까지다. 목록 기본 첫 페이지는 25행이며 전체 10,000행 중 400페이지다.
- 브라우저 시간은 전체 페이지 이동 시작부터 데이터 행 표시 확인과 연속 두 번의 animation frame 완료까지다. 재고 화면은 현재 재고와 원장 양쪽 표를 확인했다. 대시보드는 최근 7일 표를 확인했다. 화면 내부 API 요청은 실제 앱의 병렬 동작을 유지한다.
- p95는 nearest-rank 방식이다. 표본 5개이므로 p95와 최댓값이 같다. 캐시가 준비된 순차 측정이며 최초 방문·느린 네트워크·다중 사용자 상황은 별도 검증이 필요하다.

## 확인된 제약과 정리

초기 실행에서는 시드 SQL 별칭 오류로 트랜잭션이 롤백되었으며 별칭을 수정했다. 다음 실행에서는 벌크 적재 직후 통계를 갱신하지 않아 원장 API가 HTTP 503을 반환했다. `ANALYZE`를 준비 단계에 추가한 후 모든 API와 화면 측정이 성공했다. 따라서 이 결과는 최신 통계가 있는 조건의 수치이며, 벌크 적재 후 통계 유지가 중요하다. 최초 503의 실행 계획은 수집하지 않았으므로 구체적인 계획 원인은 확정하지 않았다.

측정 완료 후 소유 테넌트 ID와 이름을 대조해 전용 재고·원장·전표·기준정보·회원·인증 계정을 삭제했다. 원본 JSON의 `cleanup` 값이 정리 완료를 기록한다. 앱 코드 변경 없이 측정 도우미의 시드와 준비 절차만 보완했다.
