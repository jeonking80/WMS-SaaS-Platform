## 촬영과 검증 범위

- 캡처용 창고를 새로 만들고 로컬 앱·실제 PostgreSQL·정식 API로 합성 업무를 처리했습니다. 공개 운영 DB는 사용하지 않았습니다.
- 원두·머그컵 수령 140 EA, 추가 과납 수령 12 EA, 실제 출하 40 EA를 반영했습니다. 최종 총실물 112 EA = 정상보관 96 + 검수·적치 10 + 보류 6 EA입니다.
- 자유 질문의 외부 AI API 호출 없이 빠른 질문의 직접 조회 도구를 촬영했습니다. 외부 모델 응답 성능을 검증한 것으로 표시하지 않습니다.
- Google Fonts 다운로드가 허용되지 않아 캡처 빌드만 시스템 한글 글꼴을 사용했습니다. 캡처 후 앱 소스를 원복했습니다.
- 시뮬레이터 이미지는 `artifacts/v2-settings-smoke/ui-desktop.png`의 기존 로컬 시험 캡처에서 발췌했습니다. 새 실행이나 성능 합격 자료가 아닙니다.
- 이전 빌드의 전체 회귀 681개와 이번 관제·도우미 단위 검사 11개를 구분했습니다. 실제 현장 운영·공식 혼잡 시험 합격을 주장하지 않습니다.
- PDF의 목차는 별도 목록 대신 쪽별 주제를 사용하며 참조 URL은 클릭 가능합니다. 작성자·개발 기간·지원 직무는 최종 제출 시 확정합니다.

## 수정·재생성

문구·배치의 원본은 [PDF 생성 스크립트](../scripts/build-portfolio.mjs)이며 화면은 [캡처 폴더](assets/portfolio)에 있습니다. HTML에는 이미지를 포함하여 별도 이미지 파일 없이 열 수 있습니다.

```sh
node scripts/build-portfolio.mjs
```

Node.js와 프로젝트의 Playwright, Chromium 및 한글 글꼴이 필요합니다. 기본 Chromium 경로는 `/usr/bin/chromium`이며 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정할 수 있습니다. 문서 생성은 외부 AI나 운영 앱에 요청하지 않습니다.
