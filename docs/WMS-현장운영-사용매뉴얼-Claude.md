# WMS 현장 운영 사용 매뉴얼 (Claude 버전)

전체 메뉴를 다루는 GPT 버전은 [WMS Lite 사용자 매뉴얼](WMS-현장운영-사용매뉴얼.md)이다. 이 Claude 버전은 현장 운영 화면 개편(지금 할 일 안내, 단계 진행 표시, 스캔 순서표, 확정 전 할 일)에 맞춘 입고·출고 중심 요약이다.

대상 화면: `/dashboard/v2` (현장 운영). 화면이 다음 할 일을 직접 안내하므로, 이 문서는 처음 쓰는 사람이 화면 구성을 빠르게 익히기 위한 요약이다. 업무 규칙과 수량 정의는 [고도화 기획서](WMS-현장운영-고도화-기획서.md) 7~9장을 따른다.

## 1. 화면 구성

| 위치 | 내용 |
| --- | --- |
| 상단 작업 바 | 현재 창고, 새로고침, **단말 잠금·교대 로그아웃** |
| 상태 줄 | 회사, 작업자, 연결 상태(● 온라인 / 연결 끊김), 운영·시험 환경, 현재 창고 선택, 조회 기준 시각 |
| 현장 업무 탭 | 업무 대기열 · 입고 작업 · 출고 작업 · 반품 작업. 주황 숫자는 처리할 업무 건수 |
| 관리 탭 | 재고·실사·승인, 기준정보·CSV, 교대·일일 마감, 연계 관리, 계정·연계 키, 기존 창고 전환 |

색의 의미는 모든 화면에서 같다. 파랑은 지금 할 일, 주황은 남은 수량이나 확정 전에 할 일, 녹색은 완료, 빨강은 부족이나 오류를 뜻한다.

## 2. 업무 대기열 (홈)

1. **무엇을 하시겠어요?**의 **입고예정 등록** 또는 **출고 주문 등록**을 누르면 해당 등록 화면이 바로 열린다. 조회자에게는 보이지 않는다.
2. 기준정보(품목, 수령·보관·포장 대기 위치, 공급처·납품처·배송지)가 비어 있으면 **업무 시작 전 준비가 필요합니다** 안내가 나온다. 관리자는 **기준정보·CSV로 이동**을 눌러 등록하고, 작업자는 관리자에게 요청한다.
3. 숫자 카드(미수령·검수 대기·적치 대기·미출하 주문·승인 대기·반품 진행)를 누르면 해당 목록으로 이동한다.
4. **지금 처리할 작업**은 미완료 업무만 보여준다. 출고는 납기가 빠른 순서다. 각 줄의 `▶`는 다음에 할 일과 수량이다(예: `▶ 검수할 수량 12 EA`). 누르면 그 단계가 열린다.

## 3. 입고: 등록 → 1 수령 → 2 검수 → 3 적치

1. **입고 작업 → 신규 등록**을 누른다. 입고 예정일은 **오늘 18:00 / 내일 09:00 / 내일 18:00** 버튼으로 채울 수 있다. 외부 업무번호를 비우면 자동 번호가 붙는다. 등록만으로는 재고가 늘지 않는다.
2. 등록하면 **지금 할 일: 수령할 수량 N EA**와 **1 수령** 단계가 열린다.
3. 스캔 순서는 검은 스캔 패널의 번호(① 위치 → ② 품목 → ③ 확인)를 따른다. PC에서는 스캔 입력칸에 커서가 자동으로 놓인다.
   - 도착 위치 바코드를 스캔한다.
   - 품목 바코드를 스캔한다. 스캔할 때마다 등록된 포장 단위만큼 수량이 늘어난다(BOX12를 두 번 스캔하면 24 EA).
   - 실물과 수량을 확인하고 확인란을 체크한 뒤 **실물 수령 확정**을 누른다.
4. 확정 버튼 위의 주황색 **확정 전 할 일**은 아직 빠진 동작을 알려준다. 스캔이 되지 않으면 **스캔 실패 · 검색 선택으로 실물 대조**를 체크하고, 수량·위치와 대체 사유를 입력한다.
5. 수령을 확정하면 **2 검수**로 넘어간다. 현재 위치와 품목을 스캔하고 판정(정상 / 보류·파손)을 고른 뒤 확정한다.
6. **3 적치**에서는 보관 위치와 품목을 스캔하고 확정한다.
7. 단계 버튼에는 `N EA 남음`(주황), `✓ 완료`(녹색), `대기 없음`이 표시된다. 일부만 처리했다면 남은 수량을 같은 단계에서 이어서 처리한다.
8. 더 도착하지 않을 잔량, 초과 도착분, 품질 보류는 **과납·잔량·보류**에서 처리한다. 과납 인수와 일부 수령 예정의 잔량 마감은 다른 책임자의 승인이 필요하다.

## 4. 출고: 등록 → 1 예약 → 2 피킹 → 3 포장 → 4 인계·배송

1. **출고 작업 → 신규 등록**에서 납품처, 배송지, 납기, 품목·수량을 입력한다.
   - 품목을 고르면 `창고 가용 N EA (참고)`가 보인다. 부족하면 빨간색으로 표시된다.
   - 납품처에 배송지가 없으면 안내가 나온다.
2. **1 예약**에서는 품목별 `예약할 수량`과 `창고 가용 (참고)`을 비교한다.
   - 충분하면 **잔량 전체 예약**이 파란 버튼으로 표시된다.
   - 부족하면 경고와 함께 **가능 수량만 예약**이 파란 버튼으로 표시된다. 전체 예약은 부족하면 아무것도 예약하지 않는다.
3. **2 피킹**에서는 출발(예약) 위치, 포장 대기 위치, 품목 순으로 스캔하고 확정한다. 실물이 부족하면 **실물 부족 발견**에서 부족 예약을 해제하고 위치 점검을 요청한다.
4. **3 포장**에서는 대기 위치와 품목을 스캔하고, 필요하면 무게를 입력한 뒤 확정한다. 포장 하나는 최대 20명세다.
5. **4 인계·배송**에서는 출하할 포장을 선택한다(완료 포장이 하나면 자동 선택). 운송사·운송수단과 실제 인계자를 입력한다(로그인한 작업자 이름이 기본값). 마지막 확인란을 체크한 뒤 **인계·출하 확정**을 누른다. 이 순간에만 재고가 차감된다.
6. 출하 후 배송 상태(운송중·배송완료·실패·분실)는 같은 화면 아래 출하 카드에서 기록하거나 정정한다.
7. 주문 취소, 취소품 반납, 파손 격리는 **취소·파손·대체**에서 처리한다.

## 5. 담당자와 교대

- 업무 상세 아래 **담당자 · 잔량 인계**에서 다음 담당자와 사유를 지정한다. 완료 실적과 남은 수량은 그대로 이어진다.
- **현재 단계 잔량 계속**을 누르면 처리 영역으로 이동한다. **처리된 수량의 다음 단계**를 누르면 다음 단계가 열린다.
- 교대할 때는 **교대·일일 마감**에서 남은 업무를 인계한 뒤 **단말 잠금·교대 로그아웃**을 누른다.

## 6. 오류와 연결 문제

- 화면 위의 주황 알림은 원인과 다음 조치를 알려준다(예: 다른 작업자가 변경했으니 새로고침 후 잔량을 확인).
- 연결이 끊기면 상태 줄이 빨갛게 바뀌고 새 확정을 막는다.
- 결과를 받지 못한 확정은 **확정 결과 복구**에서 **원래 확정 결과 조회** 또는 **원래 요청 그대로 재전송**으로 처리한다. 같은 실물을 새 작업으로 다시 등록하지 않는다.
