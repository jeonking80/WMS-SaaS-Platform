# 공급처 비활성화와 미완료 실물 작업 검증

기획8.1 / MD-01은 미완료 작업이 남은 기준정보의 비활성화를 금지한다. 기존 공급처 검사는 미수령 예정 잔량만 확인해, 모두 수령한 뒤 검수·적치·보류 실물이 남은 공급처를 비활성화할 수 있었다.

추가 migration `1792368000021_v2-supplier-pending-lots.sql`은 **22번째 migration**이다. 기존0020 및 적용 이력을 수정하지 않았다. 같은 회사의 공급처가 연결된 lot에 `pending>0 OR normal>0 OR hold>0`이면 비활성화를 막는다. 입고 마감은 미수령 잔량만 마감하므로 이 조건은 `closed`와 무관하다. 기존 미수령 예정 잔량 검사도 유지한다.

`normal`은 이미 적치한 양을 제외한 정상 판정 잔량이므로 `putaway`를 다시 빼지 않는다. 과납 인수 승인은 B를 해소하지 않아 승인만으로 공급처를 비활성화할 수 없다. `quality_hold`는 `hold`의 일부이므로 중복 계산하지 않는다. 역사적 `quantity`·`putaway`·`released`·`approved`만으로 영구 차단하지 않으며, 모든 lot의 세 잔량이0이고 다른 미완료 작업이 없으면 완료된 S 재고와 공급처 스냅샷을 유지하면서 비활성화할 수 있다. 재고의 공급처 추적 범위를 새로 도입하지 않았다.

서비스와 직접 SQL 트리거가 사용하는 공통 함수를 교체했다. 함수 소유자·ACL을 유지하며 증분 적용과 down 모두 저장 `search_path`의 마지막에 `pg_temp`를 명시한다. down은0020의 함수 정의를 복원한다.
