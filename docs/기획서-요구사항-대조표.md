# 원본 기획서 요구사항 대조표

감사 기준일: 2026-10-20. 원본 [기획서](WMS-Lite-프로젝트-기획서-초안.md)와 [개발계획서](WMS-Lite-개발계획서.md)를 변경하지 않고 코드·테스트·기존 검증 기록을 대조했다. 이 문서는 정적 감사이며 테스트를 새로 실행한 결과가 아니다. **구현 근거가 있는 것, 기존 검증 기록이 있는 것, 현재 버전에서 다시 확인해야 하는 것을 구분한다. 전체 프로젝트 완료 선언이 아니다.**

경로는 저장소 루트 기준이다. 아래 테스트 파일은 실행 가능한 검증 근거이며, 파일 존재만으로 이번 실행의 통과를 뜻하지 않는다. 최신 전체 실행은 종료 코드0으로 단위153개·DB통합55개·E2E34개 및 타입검사·빌드를 통과했다. 상세는 [잔여 작업 검증 결과](기획서-잔여작업-검증결과.md)를 참고한다.

## 감사 결론

원본의 필수 업무 기능에 대해 위 근거 외의 새로운 미구현 기능은 이번 정적 감사에서 발견하지 않았다. 9.4 오류 추적 포함 전체 자동 검증과 최신 별도 DB 복원·성능 검증은 통과했다. 최신 영상도 실제 생성·검수했다. 이후 2026-10-20 공개 배포 후 대표 업무와 공개 A↔B 양방향 API 격리를 실제 실행하여 기존 미완료 조건을 충족했다. 공개 회사 전환 UI와 제공자 복원까지 새로 검증한 것은 아니다. 기존 단계 문서의 테스트 수와 배포 상태는 작성 당시 결과이며 최신 상태로 자동 승계하지 않는다.

원본 15장의 AI 조회 도우미는 명시적인 선택 확장이다. 3.3의 ERP·택배·바코드·LOT·예약·운송·회계·결제·3D·예측과 공개 회원가입·복수회사 전환은 초기 제외 범위다. 이 기능들을 만들지 않았다는 이유로 필수 범위를 미완료로 분류하지 않는다. API 예시 `/api/inventory-documents`는 구현의 `/api/documents`로 구체화되어 API 명세에 기록되어 있으며, 고정된 필수 URL 누락으로 판단하지 않는다.
