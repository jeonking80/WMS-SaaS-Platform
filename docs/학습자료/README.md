## 이 프로젝트를 한 문장으로

> 여러 회사가 함께 쓰는 창고관리 SaaS로, 재고가 틀리지 않게 하는 규칙(불변 원장·멱등 처리·승인 분리·회사 격리)을 DB와 테스트로 보장하고, 그 위에 오퍼레이터용 운영 관제와 AI 조회 도우미를 얹었습니다.

## 솔직하게 말해야 할 것

- 실제 창고 담당자가 실제 기기로 써 본 적은 없습니다. 가상 데이터와 시뮬레이터로 검증했습니다.
- AI 코딩 에이전트를 적극적으로 썼습니다. 그래서 이 학습 자료의 목표는 **모든 결정을 본인이 설명할 수 있는 상태**입니다.
- 범위에서 뺀 것: LOT·유통기한, 웨이브 피킹, 실제 택배사 송장 연동, 전용 PDA 앱. 왜 뺐는지도 설명할 수 있어야 합니다(01·03 참고).
