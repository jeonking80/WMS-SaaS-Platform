WMS Lite 사용자 매뉴얼

현장 운영 v2 및 기존 업무 화면 · 사용자용 1.0

이 매뉴얼은 WMS Lite에서 창고의 입고, 출고, 반품, 재고와 작업자를 관리하는 방법을 설명합니다. 작업자·책임자·관리자가 사용하는 화면과 실제 업무 순서를 기준으로 구성했습니다.

  • 접속: https://wms-saa-s-platform.vercel.app
  • 현장 운영 화면: https://wms-saa-s-platform.vercel.app/dashboard/v2
  • 대상: 관리자, 책임자, 작업자, 조회 사용자
  • 수량 단위: EA(개), 정수
  • 화면의 날짜·시각: 한국 시간

시작하기와 메뉴 안내

로그인과 창고 선택

  1. 접속 주소를 열고 로그인을 누릅니다.
  2. 회사에서 발급받은 이메일과 비밀번호로 로그인합니다. 초대받은 사용자는 초대 링크에서 비밀번호를 설정한 뒤 로그인합니다.
  3. 화면 상단의 현재 회사와 내 역할을 확인합니다.
  4. 왼쪽 현장 운영 v2를 선택합니다.
  5. 현재 창고에서 작업할 창고를 선택합니다. 검색칸은 후보를 좁히는 용도이며, 아래 선택 상자에서 실제 창고를 선택해야 합니다.
  6. 회사·작업자·창고·온라인 상태와 조회 기준 시각을 확인하고 업무를 시작합니다.

회사와 창고를 바꾸면 조회되는 업무와 재고도 달라집니다. 창고가 표시되지 않으면 관리자에게 해당 창고의 접근 권한을 요청합니다.

승인은 별도의 조건을 적용합니다. 관리자도 자신이 요청하거나 직접 처리한 실적, 직접 계수한 실사를 스스로 승인할 수 없습니다. 같은 회사에서 해당 창고의 권한을 가진 다른 승인권자가 검토해야 합니다.

공통 조작과 바코드 사용

업무 선택과 화면 읽기

입고·출고·반품 화면은 왼쪽 업무 목록과 오른쪽 상세 화면으로 구성됩니다.

  1. 업무 검색에 업무번호 또는 품목명을 입력합니다.
  2. 왼쪽 목록에서 처리할 업무를 누릅니다.
  3. 오른쪽 상단에서 계획·실적·취소·잔량과 단계별 대기 수량을 확인합니다.
  4. 처리할 단계 버튼을 누르고 아래 작업 양식을 사용합니다.

입고 상단의 잔량은 아직 수령하지 않은 예정량입니다. 잔량이 0이어도 검수 대기, 적치 대기, 보류가 남을 수 있습니다. 단계별 대기 수량까지 확인해야 합니다.

바코드 스캔으로 처리

이 화면은 키보드처럼 문자를 입력하는 USB·블루투스 스캐너를 사용합니다. 브라우저 카메라로 촬영하는 방식은 제공하지 않습니다. 스캐너가 없어도 등록된 바코드 값을 입력하고 Enter 또는 스캔 확인을 눌러 같은 입력 흐름을 사용할 수 있습니다.

사전 준비는 기준정보 등록의 바코드 절차를 따릅니다. 품목 코드나 위치 이름을 입력해도 바코드로 자동 인식되는 것은 아닙니다. 등록한 바코드 값과 일치해야 합니다.

  1. 스캔 입력칸을 클릭합니다.
  2. 화면에 표시된 순서대로 위치 바코드를 먼저 스캔합니다.
  3. 해당 품목의 바코드를 스캔합니다.
  4. 선택된 품목·원행·위치와 누적 수량을 확인합니다.
  5. 실물 대조 확인을 체크하고 해당 단계의 확정 버튼을 누릅니다.
화면 안내 스캔 순서
도착 위치 → 품목 바코드 스캔 도착 위치, 품목
현재 위치 → 품목 바코드 스캔 작업 대상 실물이 있는 현재 위치, 품목
출발 위치 → 도착 위치 → 품목 바코드 스캔 출발 위치, 도착 위치, 품목

품목 바코드를 반복 스캔하면 등록된 1회 스캔 기준수량 EA만큼 누적됩니다. 1회=1 EA인 바코드는 10회 스캔해야 10 EA입니다. BOX 바코드는 등록된 환산 수량을 사용합니다. 스캔 누적 수량과 확정할 수량이 일치해야 합니다. 한 번 스캔한 뒤 수량만 늘리는 방식으로 대체하지 않습니다.

스캔 대신 검색 선택으로 처리

라벨이 없거나 스캐너를 사용할 수 없는 경우 사용합니다.

  1. 스캔 실패 · 검색 선택으로 실물 대조를 체크합니다.
  2. 처리할 품목 명세를 선택합니다.
  3. 이번 수량 EA에 실제 수량을 입력합니다.
  4. 해당 단계에 위치 선택이 있으면 실제 위치를 선택합니다.
  5. **검색 대체 사유 (필수)**를 입력합니다. 예: ‘라벨 훼손으로 품목·위치 표기와 실물을 대조함’.
  6. 실물·위치 대조 확인을 체크하고 확정합니다.

이 절차는 수량·위치 확인을 생략하는 기능이 아닙니다. 단계가 바뀌면 새 작업 양식에서 입력과 확인을 다시 진행합니다.

일부 수량 처리와 다음 단계 이동

예를 들어 계획 100개 중 60개만 도착했다면 수령 수량을 60개로 확정합니다. 미수령 40개는 그대로 남고, 수령한 60개만 검수할 수 있습니다.

  • 현재 단계 잔량 계속: 현재 단계로 돌아가 남은 수량을 처리합니다.
  • 처리된 수량의 다음 단계: 이미 처리한 수량을 다음 단계에서 처리하도록 이동합니다.
  • 이 두 버튼은 화면 이동입니다. 자체적으로 수량을 확정하거나 잔량을 완료하지 않습니다.

수령·검수·포장이 성공하면 다음 단계 화면으로 이동할 수 있습니다. 일부 수량만 확정한 경우에는 남은 작업이 없어지는 것이 아니므로 이전 단계의 대기 수량도 확인합니다.

응답을 받지 못했을 때

확정 결과 복구가 표시되면 새 업무를 만들거나 동일 실물을 다시 확정하지 않습니다.

  1. 원래 확정 결과 조회를 누릅니다.
  2. 완료 결과가 확인되면 새로 표시된 실적과 잔량을 확인합니다.
  3. 완료 결과가 없으면 원래 요청 그대로 재전송합니다.
  4. 해결되지 않으면 업무번호·단계·발생 시각·오류 문구를 관리자에게 전달합니다.

기준정보 등록

경로: 현장 운영 v2 → 기준정보·CSV. 관리자 또는 책임자가 운영 전에 준비합니다.

권장 등록 순서는 품목·위치 → 거래처 → 배송지 → 바코드입니다. 사용하는 창고와 사용자 창고 권한도 먼저 준비되어 있어야 합니다.

품목

  1. 품목 탭에서 새 품목 등록을 누릅니다.
  2. 품목 코드와 이름, 검색어, 최소 재고 EA를 입력합니다.
  3. 활성 상태를 확인하고 저장합니다.

코드는 품목을 구분하는 기준입니다. 최소 재고는 부족 여부를 살피는 기준이며 재고를 자동으로 생성하지 않습니다. 품목을 실제 입고하려면 입고 업무를 처리해야 합니다.

위치

  1. 위치 탭에서 새 위치 등록을 누릅니다.
  2. 코드·이름과 위치 종류를 선택합니다.
  3. 우선순위를 입력하고 저장합니다. 작은 값이 먼저 추천됩니다.
위치 종류 용도
RECEIVING · 수령·검수대기 도착품 수령, 검수와 적치 전 대기
STORAGE · 정상 보관 정상 재고 보관과 예약 출발 위치
STAGING · 피킹·포장 대기 피킹 완료품과 포장 작업 대기
SHIPPING · 출하 대기 운송사 인계 전 출하 대기
HOLD · 보류 파손·품질 문제·초과 도착품 등 격리

점검중·예약 차단을 설정한 위치는 신규 예약 대상에서 제외됩니다. 실물 부족 등을 조사하고 해제할 때는 원인을 확인한 뒤 변경합니다.

거래처와 배송지

  1. 거래처 탭에서 코드를 정하고 이름을 입력합니다.
  2. 공급처·납품처 구분을 설정합니다. 두 용도를 함께 사용할 수 있습니다.
  3. 필요한 경우 외부 시스템 코드를 입력하고 저장합니다.
  4. 배송지 탭에서 배송지 이름, 받는 거래처, 수령인, 우편번호, 기본주소·상세주소, 연락 담당자·전화번호를 입력합니다.
  5. 외부 주소 코드가 있으면 함께 등록하고 저장합니다.

출고 주문에서는 선택한 납품처에 연결된 배송지를 사용합니다. 거래처만 등록하고 배송지를 등록하지 않으면 주문의 도착 주소를 선택할 수 없습니다. 저장된 업무·포장의 주소는 해당 이력을 기준으로 확인합니다. 주소록 수정이 과거 출하 기록을 바꾸는 것은 아닙니다.

바코드 등록과 라벨

  1. 바코드 탭에서 등록을 누릅니다.
  2. 바코드 값을 입력합니다.
  3. 대상 종류를 품목 또는 위치로 선택하고 실제 대상을 연결합니다.
  4. 품목 바코드라면 EA·BOX 단위와 1회 스캔 기준수량 EA를 입력합니다.
  5. 저장한 뒤 동일 라벨 인쇄로 라벨을 인쇄합니다.
  6. 실제 물건 또는 위치에 붙이고, 연결 대상과 환산 수량이 맞는지 시험합니다.

같은 바코드를 서로 다른 품목이나 위치에 중복 연결하지 않습니다. EA 바코드는 1회=1 EA이며, BOX는 등록한 고정 박스 수량을 사용합니다. 바코드의 연결 대상과 환산 수량은 저장 후 변경·재사용할 수 없습니다. 잘못 등록했다면 기존 라벨을 정리하고 새 바코드를 등록합니다.

배송 상태 기록

출하별 배송 상태에서 사건을 선택하고 배송 사건 기록을 누릅니다.

  • 인계 완료: 운송사 등에 실제 인계함
  • 운송 중: 배송 진행 중
  • 배송 완료: 수취 완료
  • 배송 실패: 미배송 사건 발생
  • 분실: 분실 사건 확인

배송 사건 기록은 출하 이후의 상태 이력이며 재고를 다시 증감하지 않습니다. 배송 완료·분실 등 종료 상태를 잘못 기록했다면 책임자의 배송 상태 정정 확정으로 사유를 남깁니다. 단순히 상태를 되돌리는 새 사건으로 덮지 않습니다.

주문 취소와 파손 대체

취소·파손·대체에서 상황에 맞는 절차를 사용합니다.

상황 처리 방법
아직 출하하지 않은 주문 잔량 취소 주문 잔량 취소 요청. 이미 피킹한 물건은 포장을 해제하고 실물 반납 절차도 진행합니다.
취소품을 보관 위치로 돌려놓음 취소품 실물 반납에서 실제 수량·위치·상태·사유를 기록합니다. 파손이면 보류 위치로 처리합니다.
피킹 후 일부 파손 발견, 주문은 계속 진행 책임자가 주문 유지 · 파손 격리로 해당 수량을 HOLD에 옮깁니다. 정상 재고를 같은 주문에 다시 예약·피킹·포장합니다.
이미 출하한 물건을 회수 출하 취소로 재고를 되살리지 않고 고객 반품으로 실제 회수를 기록합니다.

파손 격리는 주문량을 줄이거나 주문을 취소하지 않습니다. 예를 들어 주문 10개 중 2개가 파손되면 파손 2개를 보류하고 정상 2개를 대체 피킹하여 원래 10개를 출하합니다. 격리 중 H는 유지되고, 파손품은 출하에 포함하지 않습니다.

예정량·납기·배송지 수정

주문·입고 상세의 예정 수량·주문 배송지 수정을 펼칩니다. 변경할 값과 수정 사유를 입력하고 현재 버전 확인·변경 저장을 누릅니다. 예약·피킹 등 후속 작업 때문에 원행 수량을 수정할 수 없으면 잔량 취소 또는 원주문에 연결한 추가 주문으로 처리합니다.

  6. 물건이 실제 도착하면 1 수령에서 도착 수량을 확정합니다.
  7. 2 검수에서 정상·보류 판정을 기록합니다.
  8. 정상품은 3 적치에서 보관 위치에 적치합니다. 파손품은 보류 절차로 관리합니다.

반품 요청만으로 재고는 늘지 않습니다. 원출하 수량과 이전 반품 요청량을 기준으로 요청 가능량이 제한됩니다.

승인받았지만 오지 않는 반품 잔량은 사유를 남겨 승인 미수령 잔량 마감을 사용합니다. 이미 수령한 반품의 검수·적치는 계속 처리해야 합니다.

재배송은 반품을 정상 입고하는 것과 별도 업무입니다. 새 출고 주문을 만들 때 원주문·반품을 연결해 이력을 이어갑니다.

재고 조회·이동·보류

재고 7지표 읽기

경로: 재고·실사·승인 → 재고 7지표. 재고 품목·위치를 선택해 조회합니다.

지표 의미 업무에서의 해석
H · 총실물 S + P + Q + B 창고에 실제 남아 있는 전체 물량
S · 정상보관 정상 보관 수량. R 포함 보관 중인 정상품 전체
A · 가용 S에서 예약량과 사용 제한을 반영한 수량 새 주문에 예약할 수 있는 수량
R · 예약 정상보관 중 주문에 잡아둔 미피킹 수량 다른 주문에서 중복 사용하지 않도록 잡힌 물량
P · 피킹대기 피킹 완료 후 아직 출하하지 않은 수량 포장·인계 대기 물량 포함
Q · 검수·적치 수령 후 검수 또는 정상 적치 대기 아직 새 출고에 사용하지 않는 물량
B · 보류 파손·품질·과납 등 보류 수량 해제·검수 없이 출고에 사용하지 않는 물량

R은 S에 포함되므로 H에 다시 더하지 않습니다. 실사 잠금·점검·예약 대상이 아닌 위치 등에서는 A가 0일 수 있습니다. 가용 제외 사유를 함께 확인합니다.

목록의 연결 주문으로 예약·피킹 관련 주문을 보고, 원장 추적으로 해당 품목·위치의 증감을 확인합니다. 합계와 현재 필터 재고 CSV는 현재 페이지뿐 아니라 필터에 맞는 전체 행을 대상으로 합니다.

동일 창고 이동·보충

  1. 이동·보충·보류를 선택합니다.
  2. 이동할 품목과 출발 보관 위치를 확인합니다.
  3. 동일 창고 이동·보충에서 출발 위치 → 도착 STORAGE 위치 → 품목을 대조합니다.
  4. 예약되지 않은 정상 재고 범위에서 실제 이동 수량과 사유를 입력합니다.
  5. 대조 확인 후 동일 창고 이동·보충 확정을 누릅니다.

결과: 출발 위치 재고가 줄고 도착 위치 재고가 늘며 창고 H는 유지됩니다. 창고 간 이동 용도로 사용하지 않습니다.

정상 재고를 보류로 격리

정상 재고 보류 전환에서 출발 위치·HOLD 도착 위치·품목·실제 수량·사유를 입력하고 확정합니다. 정상보관 S가 줄고 보류 B가 늘며 H는 유지됩니다. 예약·후속 작업이 연결되어 있다면 먼저 해당 작업을 해소해야 할 수 있습니다.

일반 보류품 해제와 재검수

  1. 해당 일반 보류 후속에서 담당자와 잔량을 확인합니다.
  2. 일반 보류 … 해제 · 검수 대기 이동으로 실제 수량을 RECEIVING 위치로 이동합니다.
  3. 보류 해제분 검수에서 상태를 판정합니다.
  4. 보류 해제분 정상 적치로 정상품을 STORAGE 위치에 적치합니다.

해제만으로 가용 재고가 되지 않습니다. 입고·반품에 연결된 보류는 해당 원업무의 보류 처리 화면을 사용합니다.

위치 실사·재고 정정·승인

위치 실사

경로: 재고·실사·승인 → 위치 실사.

  1. 위치의 미완료 피킹·이동과 예약을 먼저 정리합니다.
  2. 실사할 위치를 선택합니다. 일반 실사는 RECEIVING·STORAGE·HOLD 위치를 대상으로 하며 피킹 재고 P 위치는 제외됩니다.
  3. 조건 확인·위치 잠금·실사 시작을 누릅니다. 잠금 중에는 해당 위치의 업무가 제한됩니다.
  4. 진행 중인 실사에서 대상 실사를 선택합니다.
  5. 품목·실물 상태 S/Q/B별로 실물 계수 EA를 입력합니다. 장부 수량을 그대로 복사하지 말고 실제로 셉니다.
  6. 차이가 있으면 재계수하고 차이 확인 후 재계수 완료를 체크합니다.
  7. 계수·차이 사유를 입력하고 계수 기록을 누릅니다.
  8. 계수 내역을 확인한 뒤 다른 책임자에게 조정 승인 요청을 합니다.
  9. 계수에 참여하지 않은 다른 승인권자가 승인 화면에서 검토합니다.
  10. 승인 결과, 재고와 원장, 위치 잠금 해제 상태를 확인합니다.

실물 수량이 0인 경우 0으로 기록합니다. 실사 중단이 필요하면 책임자가 사유를 남겨 실사 무효화·잠금 해제를 사용합니다. 이 경우 기존 계수는 승인할 수 없으므로 새 실사에서 다시 계수해야 합니다.

잘못된 실적의 재고 정정

경로: 원장·정정 → 연결된 재고 정정 요청.

  1. 원본 실적 품목을 좁히고 정정 원본 실적을 선택합니다.
  2. 원본에 연결된 반대 효과와 보상 가능한 잔량을 확인합니다.
  3. 정정 품목·위치·상태와 증감 EA를 검토합니다. 감소는 음수로 표시됩니다.
  4. 이동·적치처럼 출발과 도착 효과가 함께 있는 원본은 양쪽 명세를 같은 비율로 유지합니다.
  5. 정정 근거·사유를 입력합니다.
  6. 다른 책임자에게 정정 승인 요청을 누릅니다.
  7. 다른 승인권자의 검토 후 새 정정 원장을 확인합니다.

원본 이력은 삭제·덮어쓰기하지 않습니다. 후속 예약·피킹 등이 있으면 이를 먼저 정리해야 합니다. 단순한 실물 차이는 위치 실사를 사용하고, 잘못된 특정 실적을 되돌리는 경우 정정을 사용합니다.

승인·반려

경로: 재고·실사·승인 → 승인. 업무 대기열의 승인 대기에서도 이동할 수 있습니다.

  1. 승인 상태를 대기로 좁힙니다.
  2. 원업무·요청자·수량·이유와 연결된 실적을 확인합니다.
  3. 승인권자와 원작업자·계수자의 분리 조건을 확인합니다.
  4. 승인·반려 사유를 입력합니다.
  5. 검토 후 승인 또는 사유 남기고 반려를 누릅니다.
  6. 요청 상태와 해당 업무의 후속 작업을 확인합니다.

승인할 후보가 없으면 같은 회사의 다른 승인권자에게 해당 창고 권한을 부여해야 합니다. 타 회사 사용자를 승인자로 사용하지 않습니다. 승인 내용에 따라 재고 조정이 완료되기도 하고, 과납 승인처럼 이후 실물 해제·검수가 필요한 경우도 있습니다.

담당자 배정·교대·일일 마감

업무 담당자 지정과 잔량 인계

입고·주문·반품·실사·일반 보류 후속의 담당자 · 잔량 인계를 사용합니다.

  1. 현재 담당자와 완료 실적·잔량을 확인합니다.
  2. 다음 담당자에서 해당 창고 권한을 가진 사용자를 선택합니다.
  3. 인계 사유 · 다음 작업에 남은 물량, 위치, 진행할 단계와 주의사항을 적습니다.
  4. 잔량 인계·작업 배정을 누릅니다.
  5. 다음 담당자는 같은 업무를 열어 남은 단계부터 처리합니다.

인계는 기존 실적·주문량을 초기화하지 않습니다. 다른 작업자의 업무를 처리해야 하면 담당자부터 변경합니다. 조회 사용자에게 현장 작업을 배정하지 않습니다.

시험 환경의 자동 작업 계정과 인계할 때는 자동 작업을 일시 중지하고 미확인 요청을 정리한 후 화면의 자동 작업에서 사람으로 인계, 사람에서 자동 작업으로 인계, 자동 작업 계정 교체 중 해당 절차를 사용합니다.

교대·일일 마감

경로: 교대·일일 마감. 관리자·책임자가 진행합니다.

  1. 결과를 받지 못한 확정 요청이 있으면 먼저 복구합니다.
  2. 재고↔원장 대사가 일치하는지 확인합니다.
  3. 미수령·미적치·미출하·승인 대기·실사·반품·보류 후속 목록을 확인합니다.
  4. 각 미완료 업무에 다음 담당자와 남은 작업·사유를 입력합니다.
  5. 미확인 요청·실물·잔량 확인 항목을 체크합니다.
  6. 기준 시각 마감·인계 보고서 생성을 누릅니다.
  7. 마감 보고서 목록의 보고서 CSV를 보관합니다.
  8. 공용 단말에서는 단말 잠금·교대 로그아웃을 누릅니다.

마감은 미완료 업무를 자동 완료하거나 잔량을 지우지 않습니다. 다음 담당자에게 진행 상태를 전달하고 기준 시점의 보고서를 남깁니다. 대사가 불일치하면 마감을 강행하지 말고 관련 원장과 미확인 요청을 먼저 확인합니다.

CSV 가져오기·내보내기와 인쇄

CSV로 일괄 등록

경로: 기준정보·CSV → CSV 검증 · 정상 행 선택 적용.

  1. CSV 대상을 선택합니다. 품목·위치·거래처·배송지·바코드 또는 지원되는 입고예정·주문 대상을 선택합니다.
  2. 입력 양식 다운로드로 대상에 맞는 양식을 받습니다.
  3. 열 이름을 유지하여 작성합니다. 수량은 EA 정수로 작성하고 파일은 UTF-8 CSV로 저장합니다. 한 번에 최대 1,000행을 사용합니다.
  4. CSV 파일 업로드에서 파일을 고릅니다.
  5. 형식·참조·중복 검사를 누릅니다.
  6. 오류 행을 확인합니다. 필요하면 오류 행 CSV 다운로드로 내려받아 원본을 수정합니다.
  7. 적용할 정상 행을 선택합니다. 정상 행 전체 선택, 선택 해제를 사용할 수 있습니다.
  8. 선택한 정상 …행 적용을 누릅니다.
  9. 적용 결과와 실제 생성된 기준정보·업무를 확인합니다.

입고예정·주문의 관련 행은 업무 단위로 함께 검증됩니다. 일부 품목행이 잘못되었다면 같은 업무를 불완전하게 쪼개 적용하지 않습니다. 응답이 끊겼으면 이전 CSV 적용 결과 확인·동일 요청 재전송으로 확인합니다.

이 기능은 일반 재고 수량 덮어쓰기에 사용하지 않습니다. 개시재고는 별도 검토·승인 절차를 따릅니다.

전체 원장 조회

경로: 재고·실사·승인 → 원장·정정.

품목·위치·시작·종료 시각을 지정하고 조회합니다. 원장은 특정 처리 경계를 고정하여 페이지 이동·전체 CSV에서도 같은 범위를 유지합니다. 이후 발생한 작업을 포함하려면 최신 처리경계로 다시 조회를 누릅니다. 현재 필터 전체 원장 CSV는 현재 페이지 외의 일치 행도 내보냅니다.

CSV·인쇄물에는 거래처·배송지 등의 업무 정보가 들어갈 수 있으므로 회사의 보관·공유 기준을 따릅니다. CSV는 시스템 전체 복구용 백업을 대신하지 않습니다.

계정·권한·공용 단말

경로: 계정·연계 키. 관리자 전용입니다.

사용자 초대

  1. 회사 계정 · 초대에서 이름과 이메일을 입력합니다.
  2. 역할과 허용 창고를 선택합니다.
  3. 링크 유효 시간을 1~168시간 범위에서 정합니다.
  4. 일회 초대 링크 발급을 누릅니다.
  5. 표시된 전달할 일회 정보를 복사해 대상 사용자에게 개별 전달합니다.
  6. 사용자는 초대 링크에서 비밀번호를 설정합니다.
  7. 계정 목록을 새로고침하여 사용자 상태를 확인합니다.

초대 링크·비밀번호 재설정 링크는 공개 게시판이나 공용 매뉴얼에 올리지 않습니다. 표시되는 일회 정보는 전달을 마치면 확인·표시 닫기로 닫습니다.

역할·창고 권한 변경과 계정 중지

계정 역할 · 창고 범위 · 중지에서 대상을 선택하고 역할·창고·상태를 변경한 후 권한·상태 저장을 누릅니다. 담당 업무가 남아 있으면 인계도 확인합니다.

  • 초대를 받지 못했거나 만료됨: 초대 재발급
  • 비밀번호를 잊음: 비밀번호 재설정 링크
  • 잘못 전달한 일회 링크: 이전 일회 링크 취소

권한 부족은 다른 사용자의 계정을 공유해서 해결하지 않습니다. 관리자에게 필요한 역할·창고 권한을 요청합니다.

공용 단말 관리

사용자는 교대·자리 비움 시 단말 잠금·교대 로그아웃을 사용합니다. 자동 잠금 경고가 표시되고 계속 일하는 중이면 계속 작업을 누릅니다.

관리자는 공용 단말 자동 잠금 정책에서 무활동 시간을 분 단위로 정하고 회사 자동 잠금 정책 저장을 누릅니다. 잠금은 로그인 세션을 종료하며 미확인 확정 요청의 복구 정보는 보존합니다. 다음 로그인 시 복구 안내가 있다면 그 요청부터 확인합니다.

외부 연계 관리

외부 주문·입고예정을 보내는 시스템이나 가상 데이터 앱을 연결할 때 사용합니다. 일반 작업자가 수작업으로 입고·출고할 때 연계 키를 발급받을 필요는 없습니다.

연계 키 발급·교체·회수

관리자는 계정·연계 키 → 연계 키 · 자동 작업 계정에서 키 이름, 원천 시스템 이름, 환경, 용도, 허용 창고·작업 범위, 만료 시각을 정하고 제한 범위 키 발급을 누릅니다.

발급된 키는 연계 앱 담당자에게 안전하게 전달합니다. 주기 교체는 키 교체, 사용 중지·유출 대응은 즉시 회수를 사용합니다. 자동 작업 계정은 시험 환경·시험 회사의 제한에 맞춰 사용합니다.

사건 접수와 실제 업무 반영 확인

경로: 연계 관리 → 원천 사건 · 접수와 업무 반영.

  1. 외부 업무번호 또는 원천 시스템 이름을 정확히 입력해 검색합니다.
  2. 사건 상태와 거절·대기 사유를 확인합니다.
  3. 원인에 맞는 기준정보·선행 업무·권한 문제를 해결합니다.
  4. 필요한 경우 해당 사건의 원래 사건 재처리를 사용합니다.
  5. 사건 새로고침 후 실제 업무가 생성·반영되었는지 확인합니다.
상태 의미와 조치
accepted 접수됨. 업무 반영 완료를 의미하지 않으므로 후속 상태를 확인합니다.
dependency_wait 선행 업무·참조 정보 대기. 빠진 선행 자료를 확인합니다.
applied 업무에 반영됨. 원업무와 실적을 확인합니다.
business_rejected 업무 규칙 때문에 거절됨. 사유에 맞게 입력·업무 상태를 확인합니다.
retry_wait 재처리 대기. 원인 해결 후 같은 사건을 재처리합니다.
quarantined 격리됨. 관리자·연계 담당자가 원인과 재처리 가능 여부를 검토합니다.

**대기 사건 처리 실행 (최대 50건)**은 처리 가능한 대기 사건을 다시 진행합니다. 승인이나 실물 대조가 필요한 일을 강제로 완료하는 버튼이 아닙니다. 새 사건을 반복 생성하여 오류를 우회하지 않습니다.

운영 모니터

연계 관리의 운영 모니터에서 처리량, 업무 대기, 납기 초과, 실사 차이, 최소 가용 미달, 오스캔 거절과 기술 오류를 확인합니다. 업무 지연은 담당 업무를 열어 처리하고, 반복되는 기술 오류는 발생 시각·원천 사건·업무번호를 연계 담당자에게 전달합니다.

기존 업무 화면 사용

이 장은 왼쪽 메뉴의 기존 전표·재고 조회·확정 이력을 사용하는 창고에 해당합니다. 현장 운영으로 전환한 창고는 v2에서 새 업무를 처리하고 기존 화면은 과거 이력 확인에 사용합니다.

기존 기준정보와 배송지

기준정보 관리에서 창고 → 보관위치 → 품목 순으로 등록합니다. 품목 최소 재고와 전표 수량은 정수로 관리합니다. 배송지 관리에서 거래처·주소 검색·상세주소를 등록합니다. 작업자는 등록된 배송지를 선택하고, 관리자는 신규 배송지를 등록합니다.

기존 입고·출고·이동 전표

  1. 기존 전표에서 입고 작성·출고 작성·이동 작성을 선택합니다.
  2. 창고와 필요한 위치를 선택합니다. 입고는 도착 위치, 출고는 출발 위치와 배송지, 이동은 같은 창고의 서로 다른 출발·도착 위치를 지정합니다.
  3. 품목과 수량을 입력합니다. 전표당 최대 20개 품목, 수량은 1~1,000,000,000 EA 범위의 정수입니다.
  4. 전표 저장을 누릅니다. 업무번호가 생성되지만 아직 재고는 바뀌지 않습니다.
  5. 저장된 전표의 확정을 선택하고 확인 창의 내용을 확인합니다.
  6. 확정 실행을 누릅니다.
  7. 재고 조회, 확정 이력에서 반영 결과를 확인합니다.

저장 후 값을 바꾸었다면 다시 저장해야 확정할 수 있습니다. 출고·이동은 한 품목이라도 수량이 부족하면 전표 전체 확정이 거절됩니다. 조회된 잔고는 예약이 아니므로 확정 시 다시 검사합니다.

기존 취소와 조회

  • 미확정 초안 취소: 재고 영향 없음.
  • 관리자의 확정 취소: 반대 방향의 연결 전표·원장이 생성됩니다. 원본을 삭제하지 않습니다.
  • 확정 취소는 전표 전체 단위이며 재고 조건을 만족해야 합니다. 자동 생성된 취소 전표를 다시 취소하는 방식은 사용하지 않습니다.
  • 확정 이력: 업무번호·품목·거래처·주소, 날짜·유형·상태로 검색합니다. 자동 생성된 취소 전표 제외는 취소용 전표만 숨기며 원본을 지우지 않습니다.
  • 재고 조회 → 이력 보기: 해당 품목·위치의 변동을 확인합니다.
  • 감사 로그: 관리자가 작업자·행위·시각을 확인합니다.

운영 시작 시 재고 이관

관리자가 운영을 시작할 때 사용하는 절차입니다. 일상 입고 대신 사용하지 않습니다. 실제 이관 시점·원본 자료·담당자·승인자를 먼저 정합니다.

기존 창고를 현장 운영으로 전환

경로: 기존 창고 전환 → 기존 창고 운영 전환.

  1. 기존 창고의 초안과 미완료 업무를 정리하고 원본 잔량·백업을 확인합니다.
  2. 기존 잔고와 원장 대사가 일치하는지 확인합니다.
  3. 각 잔량의 이관 위치와 정상보관 S·검수대기 Q·보류 B 구분을 지정합니다.
  4. 필요하면 다른 상태·위치로 분할 배분을 사용합니다. 배분 합계와 실물을 대조합니다.
  5. 화면의 원본·백업·실물 확인 항목을 확인합니다.
  6. 확인한 잔량 이관·기존 업무 전환을 누릅니다.
  7. 현장 운영 재고·원장과 기존 이력 연결을 확인합니다.

전환 후 해당 창고의 새 재고 업무는 현장 운영에서 처리합니다. 기존 이력은 보존되며 기존 방식의 재고 변경은 제한됩니다. 같은 물량을 다시 입고하여 중복 반영하지 않습니다.

외부 자료로 개시재고 반입

외부 자료 개시재고 · 별도 검토를 사용합니다.

  1. 외부 원천 시스템, 자료 추출 시각, 반입 근거·사유를 입력합니다.
  2. 개시재고 CSV 양식에 맞춰 파일을 준비합니다.
  3. 업로드 후 외부 자료 형식·코드·수량 검증을 실행합니다.
  4. 미리보기의 수량·위치·상태·오류를 확인합니다.
  5. 원본·오류 포함 회차 보존·검토 요청을 합니다.
  6. 다른 적격 관리자가 보존된 원본·검토 회차를 확인하고 승인 또는 반려합니다.
  7. 승인 결과와 재고·원장을 대조합니다.

기존 재고와 중복되는 대상은 반입이 제한됩니다. 결과를 받지 못하면 외부 개시재고 요청 결과 확인 또는 원래 요청 그대로 결과 확인·재전송을 사용합니다. 파일을 바꿔 같은 재고를 다시 반입하지 않습니다.
